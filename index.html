Plane Adjustment Instructions
ALL HEIGHT MEASUREMENTS ARE TAKEN FROM THE ACTUAL BOTTOM PLANE.
1. The reference point is measured along the existing top plane.
2. Enter the reference point from LEFT. For Point 2 and every additional point, enter its distance from LEFT and choose SAME HEIGHT, UP, or DOWN. Enter an amount only for UP/DOWN.
3. Add outlets/cutouts after the plane adjustments are established.
Bottom plane changes: enter Distance from LEFT + Direction (UP/DOWN) + Amount. No negative numbers required.
Top plane adjustments: enter Distance from LEFT + Actual Height from the bottom plane. The reference point remains on the existing plane. Each additional point is calculated from the previous point. When complete, the top connects to the confirmed upper-right corner.
